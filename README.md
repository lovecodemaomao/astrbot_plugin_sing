# astrbot_plugin_sing · AI 唱歌与翻唱（阶跃星辰）

把「点歌」变成「真唱歌」的 AstrBot 插件：调用阶跃星辰 **StepAudio 3 Music**，按主题写词生成带人声与伴奏的完整歌曲，或拿一段参考音频翻唱成新的曲风。

> 唱歌模型 `stepaudio-3-music-preview` 目前处于**限时免费**阶段。正式版上线后模型 ID 会变化，届时在插件配置里切换即可。

## 功能

- `/唱歌 主题` —— 自动写词 + 生成完整歌曲，以语音消息发送
- `/翻唱` —— 发送或引用歌曲/语音，或贴 B 站、YouTube 视频链接、公开音频直链，生成相近的翻唱版本
- `--干声` —— 保留参考音频的人声音色，只重做伴奏
- 参数化：`--风格`、`--音色`、`--歌词`、`--纯音乐`、`--音频`、`--视频`
- LLM 工具 `sing_song` / `cover_song`，聊天里说「唱一首关于加班的歌」也能触发
- 每会话每日配额、同会话串行、全局并发 2，生成任务后台执行不阻塞聊天

## 安装

### 从插件市场

插件被市场收录后，可在 AstrBot WebUI 的「插件」页搜索 **AI 唱歌与翻唱** 安装；收录前请使用下面的手动安装方式。

### 手动安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/lovecodemaomao/astrbot_plugin_sing
pip install -r astrbot_plugin_sing/requirements.txt
```

装好后重启 AstrBot，或在 WebUI 插件页点「重载插件」。

## 配置

在 WebUI「插件 → AI 唱歌与翻唱 → 配置」里填写：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `api_key` | 空 | **必填**，阶跃星辰开放平台的 API Key |
| `model_id` | `stepaudio-3-music-preview` | 音乐模型 ID |
| `asr_model` | `stepaudio-2.5-asr` | 翻唱时从参考音频取词；识别失败会尝试直接翻唱，也可用 `--歌词` 指定 |
| `default_style` | 轻快 city pop，女声，温暖治愈，中速，清澈 | 原创歌曲未指定 `--风格` 时使用；翻唱默认尽量保留原曲 |
| `persona_prompt` | 空 | 写词用的人设描述，留空则写通用歌词 |
| `daily_limit` | 5 | 每个会话每天最多唱几首 |
| `max_wait_seconds` | 480 | 单次生成最长等待 |
| `poll_interval` | 8 | 轮询间隔（秒） |
| `max_ref_mb` | 20 | 参考音频大小上限 |
| `max_ref_seconds` | 360 | 参考音频时长上限 |
| `enable_llm_tools` | true | 是否允许模型自动调用唱歌工具 |
| `keep_generated_days` | 7 | 生成文件保留天数 |

API Key 申请：<https://platform.stepfun.com>

## 使用

```
/唱歌 夏天的海
/唱歌 加班 --风格 慵懒 lo-fi --音色 御姐
/唱歌 白米饭 --纯音乐
/翻唱                      # 和歌曲文件/语音一起发，或引用那条消息
/翻唱 --风格 摇滚 --音色 少年
/翻唱 --干声               # 保留参考音频的音色
/翻唱 --音频 https://example.com/song.mp3 --风格 R&B
/翻唱 https://www.bilibili.com/video/BVxxxxxxxxxx --音色 少女
```

参数说明：

| 参数 | 作用 |
|---|---|
| `--风格` / `--style` | 曲风、情绪、律动等描述，直接作为 caption |
| `--音色` / `--voice` | 预设：少女、御姐、少年、大叔、清冷、沙哑、童声、萝莉；也可写自由描述 |
| `--歌词` / `--lyrics` | 直接指定歌词，跳过自动写词/识别；`--纯音乐` 时不可同时使用 |
| `--纯音乐` | 只生成器乐，不唱 |
| `--干声` | 翻唱专用，保留参考音频音色 |
| `--音频` / `--视频` | 翻唱专用，公开音频直链或 B 站、YouTube 视频链接；链接也可以直接写在命令后 |

带空格的值请用引号包住，例如 `--风格 "轻快 city pop"`。

## 生成流程

```
/唱歌  → 写词 → 提交 text_to_music → 轮询 → 发送语音
/翻唱  → 取参考音频 → 尝试识别歌词 → 提交 music_cover / vocal_to_music → 轮询 → 发送语音
```

生成一首歌通常需要数分钟。视频链接会先提取音轨；长歌完成后分成约 55 秒一段发到 QQ。
部分视频网站会限制云服务器抓取；链接失败时，可把视频或 MP3 作为 QQ 附件发送给机器人。

## 常见问题

**提示「API Key 无效」**
去平台确认 Key 是否有效、是否开通了该模型权限。

**提示「额度不足」**
预览版限免结束后按平台计费，检查账户余额。

**提示「参考音频里没有检测到有效人声」**
`--干声` 模式要求输入是干净的人声；带伴奏的歌曲请用普通翻唱模式。

**语音发不出来**
完整歌曲的单条语音可能被 QQ 拒绝，插件会先拆成约 55 秒的片段，逐段发送。语音发送依赖 FFmpeg，请确认运行环境已安装。

**翻唱歌词对不上原曲**
翻唱会优先用语音识别取词；识别失败时仍会根据原音频生成，但歌词可能变化。想尽量保留原词时可用 `--歌词` 指定。生成式翻唱也不能保证每个音符都与原曲一致。

## 合规提示

- 翻唱功能仅用于处理**你拥有合法授权**的音频素材。
- 请勿上传或传播未经授权的歌曲、录音。
- 生成内容对外发布时，请遵守当地关于人工智能生成内容标识的规定。
